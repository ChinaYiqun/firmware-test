# 全部公开题：OpenCode + 本地 Qwen FP8，L0/L3

本目录冻结 EmbedEval 本地快照的 **219 道公开题**（Zephyr 158、Embedded Linux 51、ESP-IDF 5、STM32 HAL 4、FreeRTOS 1）。每题都有 `prompt.md`、`reference/main.c`、`checks/static.py` 和 `checks/behavior.py`；219 个参考实现均通过 L0/L3 健康检查。只执行 L0 静态规则和 L3 领域启发式检查，**不执行 L1 编译或 L2 运行**，因此无需安装各平台 SDK、Docker 或硬件工具链。

## 一键启动

先启动本地模型服务，确认 `http://127.0.0.1:18931/v1/models` 中有 `qwen3.8-27b-coder390-fp8`。双击 **`start.cmd`**：窗口默认显示 219 题，可以修改本次题数，点击“确认并开始”。终端随后显示进度条、已完成/总数和逐题状态。选择部分题目时，使用固定种子 42 从冻结清单中抽取；同样的题数始终得到同样的题集，正式运行在 `runs/run-*` 中保存实际清单与配置。

双击 **`resume.cmd`** 继续最近一次正式运行；会先显示待补题数并要求确认。也可在 PowerShell 中指定历史目录：

```powershell
.\start.ps1 -RunPath '.\runs\run-具体目录'
```

续跑使用该 run 的冻结运行器与原配置；已评分、无提交和超时的题跳过，基础设施错误和中断题重新尝试。评分源码、运行器、代理、OpenCode 版本或配置变化时拒绝合并到旧 run。每次新运行都是独立目录。

## 模型请求与安全边界

- 模型 ID：`qwen3.8-27b-coder390-fp8`；上游：本地 `http://127.0.0.1:18931/v1/chat/completions`。
- 本机请求适配器保证每次请求 `temperature: 0`、`chat_template_kwargs.enable_thinking: false`，输出上限设为 16384 Token。该服务报告的上下文上限为 32768；如果输入和输出预算合计超出上下文，适配器按服务返回的输入 Token 数缩减本次输出预算，留出 512 Token 余量后重试一次。请求日志记录初始与实际输出预算、重试次数；输入本身过长时仍会报错。
- 当前服务把某些工具调用作为文本返回。适配器把识别出的文本工具调用转换为标准 OpenAI `tool_calls`；这属于本组额外协议适配，原始 `request-params.jsonl` 只记录模型、参数、HTTP 状态与转换数量，不记录提示词或密钥。
- 每题单独 Git 工作区，并验证 OpenCode 检测到的 Git 根目录确实是该题工作区；文件读写只放行该题路径，同时匹配绝对路径和工作区相对路径。禁用搜索、Shell、网页和子 Agent。正式计分前预检模型接口、越界读取拒绝和文件写入。工具权限限制不等于操作系统沙箱。
- 默认并发 2、每题 600 秒、每题 1 次。运行器不做外部重试；模型服务和 CLI 内部行为包含在单题时限内。

## 产物

`runs/run-*/` 中有 `summary.json`、`report.md`、`tasks.csv`、`results.sqlite`、逐题提交/评分/脱敏轨迹及冻结配置。`runs/dry-*/` 是离线流程测试或预检调试，不是正式模型结果。

```powershell
.\start.ps1 -Count 2 -DryRun
```

这只写入故意错误的测试提交，不调用模型；启动前仍需确认。原始分数仅表示当前 L0/L3 规则的接受结果，不能作为编译或硬件正确性的证明。
